# Проверка и поиск IPv4 — пример слоистой архитектуры на Python

Минимальный консольный проект на Python 3.10+, без сторонних зависимостей.
Программа ищет IPv4-адреса в тексте регулярным выражением, классифицирует
каждый найденный адрес (класс, private/loopback/multicast) и сохраняет
результат в историю.

## Запуск в PyCharm

1. Распакуйте архив.
2. В PyCharm выберите **File → Open** и папку `layered_ipcheck`.
3. Укажите Python 3.10 или новее как интерпретатор проекта.
4. Откройте `main.py` и нажмите **Run**.
5. История проверок сохраняется в `history.json` рядом с `main.py`.

## Меню

1. Найти и проверить IP-адрес — введите любой текст; программа найдёт в нём
   все корректные IPv4 и сохранит их в историю. Чтобы проверить один адрес,
   достаточно вставить его как текст: валидный попадёт в результат,
   невалидный — нет (см. «Бизнес-правила»).
2. Посмотреть историю запросов — список сохранённых адресов с отметкой
   `✓`/`✗`, классом и флагами.
3. Очистить историю — удаляет все записи (с подтверждением `y/n`).
0. Выход.
